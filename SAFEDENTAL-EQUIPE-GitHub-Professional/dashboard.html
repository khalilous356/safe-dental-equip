Architecture prête pour API

Dolisoft Online — stock

Synchroniser le stock du site avec votre comptoir. Utilisez votre URL API et votre jeton d'accès fourni par le service.

Google Sheets — commandes

Chaque nouvelle commande peut être envoyée automatiquement vers une feuille Google Sheets via un Webhook Apps Script.

Livraison — lancement automatique

Conservez le nom de la société de livraison, votre token API et l'endpoint. À la validation, la commande est prête à être poussée.

SMS — nouveaux arrivages

Connexion à un fournisseur SMS via webhook. Le message peut cibler les clients ayant activé les alertes d'arrivage.
